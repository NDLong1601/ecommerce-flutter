# Flutter Models Guide

Systematic approach to creating and maintaining Flutter/Dart data models following best practices and clean architecture principles.

## When to Use This Guide

Use this guide when you need to:
- Create new request or response models
- Refactor existing models
- Review model structure and serialization
- Ensure models follow clean architecture patterns
- Validate model naming conventions and organization
